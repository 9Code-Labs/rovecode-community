# Roadmap

Direction, not a promise or schedule:

1. Harden the public/private package boundary and publish stable core entry points.
2. Specify and version plugin, tool, provider, MCP, and skill interfaces.
3. Expand runnable integration examples and Windows/macOS/Linux coverage.
4. Make deterministic eval fixtures and result formats reproducible.
5. Improve supply-chain attestations and release reproducibility.

Track concrete work in public issues. Hosted account, billing, deployment, and private operations are non-goals for this repository.
